# 🌱 Mi jardín mágico

Juego para bebés para iPad con iOS 12.5.x. Funciona **sin internet** una vez instalado. Fondo oscuro, colores suaves y **sonidos muy bajitos**.

## Cómo se juega
- **Menú de la izquierda (se desliza):** 4 semillas del bioma + 💧 regadera + ☁️ nube.
- **Tocar el suelo (o el cielo, la semilla cae):** siembra. Arrastrar el dedo siembra una hilera.
- **Tocar una planta, o usar regadera/nube:** la riega y crece hasta florecer.
- **Flechitas a los lados:** cambian de bioma (🌸 jardín, 🥕 huerto, 🌲 bosque, 🌵 desierto, 🐠 estanque). Cada uno tiene 4 semillas distintas: 20 en total.
- **Animalitos y partículas flotantes:** al tocarlos brillan y hacen un sonidito suave.
